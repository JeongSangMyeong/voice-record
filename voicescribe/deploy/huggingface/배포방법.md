# 다른 사람에게 링크로 주는 방법

이 폴더의 파일 3개(`app.py`, `requirements.txt`, `README.md`)를
Hugging Face Spaces 에 올리면 **주소만 보내면 되는 웹페이지**가 됩니다.
무료이고, 받는 사람은 아무것도 설치하지 않아도 됩니다. 휴대폰에서도 열립니다.

## 방법 1 — PC 에서 (제일 쉬움, 1분)

```bash
pip install huggingface_hub
hf auth login                       # 허깅페이스 토큰 입력 (write 권한)
cd voicescribe/deploy/huggingface
./deploy.sh 내아이디/voicescribe
```

끝나면 `https://huggingface.co/spaces/내아이디/voicescribe` 주소가 나옵니다.
이 주소를 상대방에게 보내면 됩니다.

## 방법 2 — 휴대폰 브라우저에서

1. <https://huggingface.co/new-space> 접속
2. 이름 `voicescribe`, SDK 는 **Gradio**, 공개 여부는 **Public** 선택 후 만들기
3. 만들어진 페이지에서 **Files** → **Add file** → **Create a new file**
4. 아래 3개를 각각 만들어 이 폴더의 내용을 그대로 붙여넣기
   - `README.md`
   - `requirements.txt`
   - `app.py`  (길어서 PC 에서 하는 편이 편합니다)
5. 빌드가 끝나면 (2~3분) 주소가 열립니다

> `app.py` 가 길어서 휴대폰 붙여넣기는 번거롭습니다. PC 를 쓸 수 있으면 방법 1 을 권합니다.

## 알아 둘 점

- **녹음 파일이 Hugging Face 서버로 올라갑니다.** 내 PC 안에서만 처리하려면
  이 웹 버전 대신 저장소 기본 프로그램(`voicescribe web`)을 쓰세요.
- 무료 Space 는 한동안 아무도 안 쓰면 잠자기 상태가 되고, 다시 열면 깨어나는 데
  30초쯤 걸립니다.
- 첫 실행 때 음성인식 모델(약 240MB)을 받으므로 1~2분 걸립니다. 그 뒤로는 빠릅니다.
- 무료 Space 사양은 CPU 2코어입니다. 1시간짜리 긴 녹음은 몇 분 걸릴 수 있습니다.
