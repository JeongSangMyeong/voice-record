# 다른 사람 PC 에 설치해 주는 방법

받는 사람은 **아무것도 미리 깔지 않아도 됩니다.** 파이썬도 필요 없습니다.
첫 실행 때 필요한 것을 알아서 받습니다.

## 1단계 — 압축 파일 만들기

PC 에서 한 번만 실행하면 `VoiceScribe.zip` 이 만들어집니다.

```bash
cd voicescribe/deploy/pc
./압축만들기.sh          # 윈도우면: 압축만들기.bat
```

만들어진 `VoiceScribe.zip` 을 카카오톡·메일·USB 등으로 전달하면 됩니다. (약 300KB)

## 2단계 — 받는 사람이 할 일

이 내용을 그대로 전달해 주세요.

> 1. `VoiceScribe.zip` 을 **압축 풀기** (바탕화면 같은 곳에)
> 2. 폴더 안 `deploy` → `pc` 폴더로 들어가기
> 3. **`시작-윈도우.bat` 더블클릭** (맥이면 `시작-맥.command`)
>    - 휴대폰에서도 쓰려면 대신 **`시작-휴대폰도쓰기.bat`** 을 실행하세요
> 4. 검은 창이 뜨고 설치가 진행됩니다. **처음 한 번만 5분쯤 걸립니다.**
> 5. 브라우저가 자동으로 열립니다. 녹음 파일을 끌어다 놓고 **받아쓰기 시작** 누르면 끝
>
> 다음부터는 같은 파일을 더블클릭하면 바로 열립니다.

### 맥에서 "확인되지 않은 개발자" 경고가 뜬다면

`시작-맥.command` 를 **우클릭 → 열기** 를 선택하면 실행됩니다.
(더블클릭 대신 우클릭이라는 점만 다릅니다.)

### 윈도우에서 파란 경고창이 뜬다면

**추가 정보** → **실행** 을 누르면 됩니다. 서명되지 않은 스크립트라서 뜨는 안내입니다.

## 자주 있는 문제

| 증상 | 해결 |
| --- | --- |
| 검은 창이 바로 닫힘 | 압축을 풀지 않고 zip 안에서 바로 실행한 경우입니다. 압축을 먼저 푸세요 |
| "준비 도구 설치에 실패" | 인터넷 연결 문제입니다. 회사 방화벽이면 IT 팀에 문의하세요 |
| 설치가 너무 오래 걸림 | 첫 실행은 5분, 첫 받아쓰기는 모델 받느라 1~2분 더 걸립니다. 정상입니다 |
| 브라우저가 안 열림 | 주소창에 `http://127.0.0.1:7860` 을 직접 입력하세요 |

## 휴대폰에서 쓰기

`시작-휴대폰도쓰기.bat` 을 실행하면 검은 창에 **주소와 QR 코드**가 나옵니다.

1. 휴대폰을 그 PC 와 **같은 와이파이**에 연결
2. 휴대폰 카메라로 QR 을 찍거나, 나온 주소를 브라우저에 입력
3. "안전하지 않은 사이트" 경고가 뜨면 **고급 → 계속 진행**
   (그 PC 가 직접 만든 인증서라서 뜨는 경고입니다)

이때도 **녹음 파일은 그 PC 안에서만 처리됩니다.** 인터넷으로 나가지 않습니다.

| 증상 | 해결 |
| --- | --- |
| 휴대폰에서 주소가 안 열림 | 같은 와이파이인지 확인. 회사·카페 와이파이는 기기 간 통신을 막는 경우가 있습니다 |
| 마이크 버튼이 안 눌림 | `시작-휴대폰도쓰기` 로 실행했는지 확인하세요(일반 실행은 마이크가 안 됩니다) |
| 경고 화면에서 못 넘어감 | 크롬은 "고급", 사파리는 "세부 사항 표시" → "이 웹사이트 방문" |

## 알아 둘 점

- **녹음 파일이 인터넷으로 나가지 않습니다.** 전부 그 PC 안에서 처리됩니다.
- 첫 실행에 약 350MB(프로그램 + 음성인식 모델)를 받습니다. 그 뒤로는 인터넷 없이도 됩니다.
- 한국어·일본어·중국어·영어는 빠른 엔진으로 처리합니다.
  그 밖의 언어가 필요하면 폴더에서 `.venv/bin/pip install faster-whisper` 를 한 번 더 실행하세요.
