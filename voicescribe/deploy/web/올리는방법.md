# 인터넷에 올리는 방법 (서버 필요 없음)

이 폴더의 파일 두 개(`index.html`, `worker.js`)가 전부입니다.
어디든 올려두면 주소만으로 쓸 수 있고, **PC 를 켜 둘 필요가 없습니다.**

변환은 접속한 사람의 **기기 안에서** 이루어집니다. 녹음이 서버로 올라가지 않습니다.

## 방법 A — GitHub Pages (제일 간단, 저장소가 공개여야 함)

1. 깃허브에서 저장소를 하나 만듭니다(공개).
2. 이 폴더의 `index.html` 과 `worker.js` 를 저장소 맨 위에 올립니다.
3. 저장소 **Settings** → 왼쪽 **Pages** → Source 를 **Deploy from a branch**,
   Branch 를 **main / (root)** 으로 지정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 이 열립니다.

> 무료 플랜에서는 저장소가 **공개**여야 Pages 를 쓸 수 있습니다.
> 비공개로 두고 싶으면 방법 B 를 쓰세요.

## 방법 B — Cloudflare Pages (비공개 저장소도 무료)

Cloudflare 는 인터넷 인프라 회사이고, 그중 Pages 는 홈페이지를 무료로 올려주는 서비스입니다.
이 용도로는 요금이 들지 않습니다.

1. <https://dash.cloudflare.com> 가입 (무료)
2. **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. 깃허브 계정을 연결하고 저장소를 고릅니다(비공개도 됩니다)
4. 빌드 설정은 이렇게 둡니다
   - Framework preset: **None**
   - Build command: **비워 둠**
   - Build output directory: `voicescribe/deploy/web`
     (파일을 저장소 맨 위에 뒀다면 `/`)
5. 저장하면 `https://<이름>.pages.dev` 주소가 나옵니다

이후에는 깃에 올릴 때마다 자동으로 반영됩니다.

## 방법 C — 그냥 파일로 주기

인터넷에 안 올리고 파일만 건네도 됩니다. 다만 **파일을 직접 열면(`file://`) 동작하지 않습니다.**
브라우저 보안 규칙 때문입니다. 위 두 방법 중 하나를 쓰는 편이 낫습니다.

---

## 알아 둘 점

- **처음 열 때 모델을 내려받습니다.** 기본값(권장)은 약 250MB 입니다.
  한 번 받으면 브라우저에 저장되어 다음부터는 바로 열립니다.
  데이터를 아끼려면 와이파이에서 처음 한 번 열어 두세요.
- **속도는 기기 성능을 탑니다.** 최신 아이폰은 쓸 만하고, 오래된 기기는 느립니다.
  느리면 '정확도' 를 `보통` 이나 `낮음` 으로 낮춰 보세요.
- **정확도는 PC 판보다 낮습니다.** 휴대폰에서 돌리려고 작은 모델을 쓰기 때문입니다.
  회의록처럼 정확도가 중요하면 PC 판(`deploy/pc`)을 쓰세요.
- **아이폰 주의:** 사파리는 오래 안 쓴 사이트의 저장 공간을 지우는 경우가 있습니다.
  그러면 모델을 다시 받습니다. **홈 화면에 추가**해 두면 덜 지워집니다.
  (사파리에서 공유 버튼 → 홈 화면에 추가)
